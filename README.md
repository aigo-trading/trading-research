我是周栩棋，这里记录我对交易的思考、学习与研究过程。

- 交易观点：对市场结构、订单流与交易行为的思考

## 阅读说明

文章会尽量区分个人观点、待验证假设与测试结果，并注明适用条件及局限。随着认识深入，内容可能修订，修改历史保留在仓库中。

内容用于学习交流，不构成个性化投资建议，也不承诺收益。
